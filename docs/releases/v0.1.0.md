# Gemini Terminal 0.1.0 — Alpha

Lançamento de 21 de outubro de 2026. Primeira versão alpha do agente de terminal para arquivos e análise de dados com Gemini.

## Destaques

- Instalação mínima ou com extras para dados, gráficos, PDF, SQL Server, Hive e Airflow.
- Sessões persistentes, autocomplete, histórico, trace e diagnósticos locais.
- Configuração global e catálogo de recursos editável com `/config resources`.
- Validação de argumentos, allowlists, confirmação de operações sensíveis e auditoria.
- Fallback entre modelos, controle de timeouts e classificação de erros 429.

## Instalação

Instale esta versão com:

```powershell
pipx install "gemini-code-terminal[all] @ git+https://github.com/Gui-Amaral2003/Gemini_Code.git@v0.1.0"
gemini-terminal --config
gemini-terminal
```

Omita `[all]` para uma instalação mínima. Os pré-requisitos e a instalação de `pipx` estão no [README](https://github.com/Gui-Amaral2003/Gemini_Code/blob/v0.1.0/README.md#quick-start).

Os arquivos `gemini_code_terminal-0.1.0-py3-none-any.whl` e `gemini_code_terminal-0.1.0.tar.gz` são, respectivamente, o wheel instalável e a distribuição de código-fonte. O arquivo `SHA256SUMS.txt` contém os hashes dos dois pacotes.

## Migração

O `.env` agora fica no diretório padrão do aplicativo, independentemente da pasta atual. Variáveis do ambiente têm prioridade. Use `GEMINI_ENV_PATH` no ambiente para selecionar explicitamente outro arquivo.

O catálogo começa vazio; recursos anteriormente cadastrados no código devem ser adicionados por `/config resources`. Arquivos antigos não são sobrescritos ou migrados automaticamente. Veja [configuração e migração](https://github.com/Gui-Amaral2003/Gemini_Code/blob/v0.1.0/docs/configuration.md).

## Limitações conhecidas

- Requer reiniciar o terminal após editar configuração ou recursos.
- O cadastro valida estrutura e permissões locais, sem testar conexão ou descobrir colunas no banco.
- O editor de tabelas cadastra somente leitura; novas permissões de escrita são configuradas no TOML.
- A quota exibida é uma estimativa local.
- O timeout de uma thread não interrompe uma função já iniciada.
- Scripts não têm sandbox de sistema operacional.
- CSVs de exemplo e scripts de demonstração exigem download ou clone separado.
